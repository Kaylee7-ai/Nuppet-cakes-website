# Nupet Cakes — Independent Website & Online Store Concept

A responsive, static website concept for Nupet Cakes, a cake shop publicly listed in Spintex, Accra. This is an independent proposal and is **not affiliated with, approved by, or operated by Nupet Cakes**. Do not present it as the business's official website until the owner has reviewed and approved it.

## Run locally
Open `index.html` in a modern browser. No build step or package installation is required.

## What's included
- Luxury patisserie visual direction: ivory, cocoa, rose-gold and blush.
- Responsive navigation and mobile sticky call / WhatsApp bar.
- Seven occasion collections with four illustrative sample design cards each.
- Search and occasion filters; flavour and size preferences are captured as enquiry preferences, not verified menu data.
- Quick-view modal and enquiry basket that combines selected sample designs into one WhatsApp message.
- Custom enquiry form with past-date validation, optional inspiration image selection and WhatsApp message preparation.
- Email draft fallback with no invented recipient address.
- Flavour / size guidance, how-to-order, public-review theme summary, FAQ, contact details and map search.
- SEO metadata, Open Graph tags, and LocalBusiness structured data.
- Reduced-motion support, semantic landmarks, visible focus states and lazy-loaded collection photography.

## Owner approval checklist before launch
1. Confirm official business name, pickup address, phone, opening hours and contact channels.
2. Confirm whether the business accepts WhatsApp orders and supply its preferred WhatsApp number/link and email.
3. Supply approved real product photographs and permission to publish them; replace every illustrative image.
4. Confirm actual cake catalogue, flavours, sizes, servings, prices and availability.
5. Confirm order lead times, delivery zones and fees, pickup instructions, deposit/payment methods, cancellations, refunds and allergen handling.
6. Approve the About/story text, public review references, social links, map pin, SEO description and all customer-facing copy.
7. Connect an owner-approved domain and analytics only after approval.

## Deployment
This is a static site and can be deployed on GitHub Pages, Vercel or another static host. For GitHub Pages, publish the repository root from the chosen branch. For Vercel, import the repository and use the default static deployment settings (no build command; output directory `.`). The concept is not an active ordering system and does not process payments or store customer data.
